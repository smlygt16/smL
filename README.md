# smL

Bu depo, projelerimizde doğal ve TDK uyumlu Türkçe metin üretimi ve yapay zeka izlerini temizlemek için **turkish-anti-ai-skill** yeteneğini barındırır.

## Dahil Edilen Yetenekler
- **turkish-anti-ai-skill**: Metinlerdeki yapay zeka ve çeviri kokularını (AI slop / translationese) temizleyen, cümle mimarisini Türkçenin sondan eklemeli yapısına göre yeniden kuran kılavuz ve kurallar bütünü.
